Part 1: 
After implementing the SIFT detector to the picture, the visualization confirmed that the algorithm could somewhat accurately place large circles around large blobs and small circles around small ones. However, there are also a lot of instances where there are circles places in areas where there are no blobs at all. This is especially apparent in the top of the picture where many of the blobs are overappled and close to the other pages. While blobs were more closely accurate in the cetenr of the picture where they are more spread out, at the top and bottom of the pictures were the blobs are closer and overlap there are much more errors.

Part 2:
Altering the values of the parameters had a great effect on the amount and accuracy of the blobs. When changing around the contrast threshold value, it affected the amount of keypoints that were taken in the picture. Reducing that value resulted in a higher amount of keypoints. I found that having a value closer to 0.01 ended with the best results. Altering the edge threshold value changed the amount of points near the edges of the picture. I found that keeping this value between 2-3 had the best results. The sigma parameter affected how much blur was at each scale. I found it was best to increase this value from the 1.6 base because it resulted in more of the blobs along the corner of the picture being found. Lastly, the n0ctave layers parameter dictated how many intermediate scales there were per octave. I slightly increased this value to go more along with the sigma parameter.

Part 3:
The 128 values in the SIFT descriptor is used to represent the appearance of the local image region around a detected keypoint. It is made by dividing the keypoints local region into a 4x4 grid and computing an 8-bin orientation histogram per cell. This strucuture helps to capture the local texture pattern in a way that is invariant to scale, rotation, and lighting changes.
